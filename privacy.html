隐私政策

生效及更新日期：2026 年 11 月 11 日
适用应用：声页听吟 iOS 版

声页听吟由开发者 wrxx97 提供，是一款用于导入本地电子书、阅读及听书的工具。本政策说明应用如何处理数据，以及你可以如何管理数据和权限。

核心说明：书籍导入、阅读及克隆语音生成主要在你的设备本地完成。应用不要求注册开发者账号，不将书籍正文、参考录音或生成音频自动上传至开发者服务器，不使用广告追踪或第三方行为分析 SDK。

一、为提供功能而在设备上处理的数据

  • 书籍与阅读信息：你选择导入的书籍、文件名称、章节、封面、阅读位置及阅读设置，用于书架展示、分页、朗读和恢复进度，保存在应用的本地存储中。
  • 参考音频、录音与音色：你主动导入或录制的音频，以及相关音色数据，用于创建和使用克隆音色。语音模型在设备本地处理参考声音与待朗读文本；应用不将这些内容发送至开发者的云端推理服务，也不将其用于训练开发者的模型或进行身份识别。
  • 生成音频与缓存：生成的语音片段、章节音频、封面缩略图和任务进度，用于复用音频、播放和管理生成任务，存储在设备本地。
  • 购买与试用状态：应用通过 Apple StoreKit 获取并验证试用、购买及恢复购买的交易和权益信息，用于判断功能是否解锁。付款由 Apple 处理，开发者不会通过应用取得你的银行卡信息或 Apple 账户密码。

二、权限与用户选择

  • 麦克风：仅在你使用录制音色功能时申请，用于录制你主动开始的参考音频。拒绝授权不影响书籍阅读。你可以在 iOS「设置」中随时撤销麦克风权限。
  • 照片与文件：通过系统照片或文件选择器访问你明确选定的封面、书籍和音频，不主动扫描整个照片库或其他应用的文件。
  • 系统媒体展示：听书时，系统锁屏或实时活动可能展示书籍、章节、播放或生成进度。请根据个人需要在 iOS 设置中管理锁屏和实时活动展示，避免他人在锁屏界面看到阅读信息。

三、联网、Apple 服务与第三方页面

下载语音模型、查询商品、完成购买和恢复购买需要使用 Apple 提供的服务。Apple 可能为提供服务而处理网络地址、设备或交易信息，其处理方式适用 Apple 隐私政策。应用不会在模型下载请求中附带你的书籍正文或参考录音。

如果你开启了系统备份，应用本地数据可能由 iOS 根据你的设备设置纳入备份。备份的存储和删除受你的系统设置及 Apple 的相关服务规则管理，开发者不运营用于同步书籍或录音的服务器。

技术支持网站由 GitHub Pages 托管。访问网站或使用 GitHub Issues 反馈时，GitHub 可能处理网络地址、账号及相关访问数据，具体参见 GitHub 隐私声明。网站未集成额外的广告或统计脚本。

四、你主动提交的反馈

如果你通过技术支持入口联系开发者，我们会看到你主动提交的问题描述、App 及系统版本、设备型号、截图和 GitHub 公开账号信息，并用这些信息排查和回复问题。

GitHub Issues 是公开的。请勿提交私人录音、完整书籍、完整订单、支付信息、账户密码或其他敏感内容。你可以按 GitHub 提供的功能编辑自己的反馈，并通过支持入口提出与反馈内容有关的隐私请求。公开内容可能受第三方缓存、平台规则及保留机制影响。

五、保存、删除与撤销

本地书籍、音色及生成音频会保留至你主动删除、清理缓存、卸载应用，或由系统根据存储规则清理相关缓存。你可以在书架删除书籍，在音色页删除音色，在缓存管理中清理音频或封面缓存，在模型管理中卸载模型。删除前请自行备份需要保留的原文件。

删除应用会移除该设备上的应用本地数据，但不会取消 Apple 记录的已购权益，也不会自动移除你保存在「文件」、照片、系统备份或其他位置的副本。重新安装后可使用购买时的 Apple 账户恢复有效权益。

六、分享与安全

我们不出售书籍、录音或个人信息，不利用这些数据进行跨应用广告追踪。应用使用 iOS 的应用沙盒保存本地数据。请妥善管理设备解锁密码及备份；任何存储或传输方式都不能保证绝对安全。

请仅导入你有权使用的书籍、图片和声音；录制或导入他人的声音前，应获得相应授权。不要提交他人的敏感信息。

七、儿童使用

本应用不以收集儿童个人信息为目的。未成年人应在监护人指导下使用录音、声音克隆、购买及公开反馈功能。若你认为反馈中含有未经适当授权的未成年人个人信息，请联系开发者处理。

八、政策更新与联系

如果数据处理方式发生变化，我们会更新本页面及生效日期，并在适用情况下通过应用或其他适当方式提示。新的权限申请将由系统在使用相应功能时提示。

有关本政策、数据处理或删除请求，请通过 声页听吟技术支持 联系开发者。请先描述问题类别，不要在公开页面提交敏感信息。
